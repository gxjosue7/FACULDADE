## 📚 Disciplinas

### 🗄️ Banco de Dados (3º semestre)
Atividades práticas de modelagem e manipulação de banco de dados relacional com SQL.

| Pasta | Conteúdo |
|-------|----------|
| `Dump20260520` | Dump de base de dados compartilhada |
| `tabela_sql_exemplo` | Script de criação de tabela de exemplo |

---

### 🌐 Desenvolvimento Web — DEVWEB (3º semestre)
Atividades de front-end: estruturação, estilização e interatividade de páginas web.

| Pasta | Conteúdo |
|-------|----------|
| `HTML` | Estruturação de páginas (`atv-bg`, `atvd_bullet`) |
| `CSS` | Estilização e layout (`atvd_lincoln`, `atvd_petshop`, `atvd_shield`) |
| `JAVASCRIPT` | Interatividade e lógica no cliente (`accordion`, `airbnb`, `alcool`, `captcha`, `emprestimo`, `gallery`, `menu_hamburguer`, `to_do_list`) |
| `VUE` | Introdução ao framework Vue.js (`atvd_portifolio`) |

---

### ☕ Programação Orientada a Objetos I — POO1 (3º semestre)
Atividades de POO com foco nos pilares da orientação a objetos.

| Pasta | Conceito |
|-------|----------|
| `atvd_poo1` | Introdução a classes e objetos |
| `atvd_herança` | Herança e reutilização de código |
| `atvd_poliformismo` | Polimorfismo e sobrescrita de métodos |

---

### ☕ Programação Orientada a Objetos II — POO2 (3º e 4º semestre)
Continuidade do estudo de POO, com aplicação de testes automatizados.

| Semestre | Pasta | Conteúdo |
|----------|-------|----------|
| 3SMT | `POO2` | Início dos estudos do semestre |
| 4SMT | `POO2/atv_ecommerce` | Sistema de e-commerce (`carrinho`, `categoria`, `cliente`, `item_carrinho`, `produto`) com testes unitários via `pytest` |

---

### 🌐 Desenvolvimento Web II — DEVWEB2 (4º semestre)
Continuidade dos estudos de desenvolvimento web, em fase inicial.
